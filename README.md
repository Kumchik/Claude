# Waveform — дизайнерські накладки на вимикачі

Статичний лендинг з конструктором, натхненний форматом printesso.ru
(«дофаміновий декор для дому»): накладки на вимикачі світла з вибором
кількості клавіш, візерунка та кольору.

Сайт українською мовою, орієнтований на аудиторію в Україні, ЄС та США —
з перемикачем валют (гривня / євро / долар) та вибором форми рамки
(квадратна «quadro», вертикальна чи горизонтальна) на додачу до кількості
клавіш, візерунка та кольору. Повністю статичний (HTML/CSS/JS, без збірки
й бекенду) — відкривається як звичайний файл або розгортається на
GitHub Pages / Netlify / будь-якому статик-хостингу за кілька хвилин.

Комплект товару — дві частини: декоративні важельки, які приклеюються
прямо на клавіші вимикача, та рамка з вирізами, яка клацає зверху на
штатні кріплення (без викруток і виклику електрика) — це описано в FAQ
на сайті.

## Структура

- `index.html` — розмітка всіх секцій сторінки
- `styles.css` — стилі та прев'ю вимикачів на чистому CSS (без картинок)
- `app.js` — дані (кольори/візерунки/ціни/валюти), логіка конструктора,
  FAQ, модальне вікно замовлення

## Що обов'язково замінити перед публікацією

Усі значення нижче — заглушки для демонстрації, реальний магазин
працювати з ними не може.

1. **Назва бренду** — «Waveform». Якщо потрібно щось інше, шукайте/замінюйте
   в `index.html` (логотип, `<title>`, футер) та у футерному тексті `app.js`
   (рядок «Заявка на накладку Waveform»).
2. **Контакти** — в `index.html` (секція `#contacts` і футер) та в `app.js`
   (`TELEGRAM_USERNAME`):
   - Telegram-юзернейм `your_shop_username`
   - Email `hello@example.com`
   - Телефон `+380 00 000 0000`
   - Посилання Instagram/TikTok у футері (зараз `#`)
3. **Ціни та курси валют** — усе в `app.js`:
   - `KEY_BASE_PRICE` — базова ціна за кількість клавіш, вказана в **гривнях**
   - `surcharge` у кожного візерунка в `PATTERNS` та у покриття в `FINISHES`
   - `CURRENCIES` — курси EUR/USD до UAH, якими перераховуються ціни на льоту.
     Це орієнтовні курси, вони застарівають — оновлюйте регулярно, або, що
     надійніше для міжнародного магазину, замініть автоконвертацію на
     окремий прайс-лист під кожен ринок (інша логістика/матеріали в ЄС і
     США зазвичай означають іншу економіку, не просто перерахунок за курсом).
4. **Фото товарів** — прев'ю вимикачів зараз малюються CSS-візерунками
   (без фотографій), щоб сайт не залежав від зовнішніх зображень. Коли
   з'являться реальні фото готових накладок, варто замінити блоки
   `.switch-frame` у картках каталогу на `<img>` зі справжніми фотографіями.
5. **Відправлення заявки** — зараз кнопка «Оформити замовлення» відкриває
   вікно зі зведенням замовлення, яке можна скопіювати або надіслати через
   `t.me/share/url` (користувач сам обирає, кому переслати). Для повноцінного
   автоматичного надсилання у ваш чат підключіть Telegram-бота з
   `sendMessage` через власний бекенд, або форму на кшталт Formspree/Getform
   (з підтримкою міжнародних клієнтів варто додати ще й email/WhatsApp-канал).

## Локальний перегляд

Просто відкрийте `index.html` у браузері, або підніміть локальний сервер:

```bash
python3 -m http.server 8080
```

і відкрийте `http://localhost:8080`.

## Подальший розвиток

- Реальні фото колекцій замість CSS-прев'ю
- Окремі прайс-листи під Україну/ЄС/США замість автоконвертації за курсом
- Бекенд для прийому та зберігання заявок, онлайн-оплата (картка, PayPal)
- Особистий кабінет / статус замовлення

- Багатомовність (наразі лише українська; можна додати EN-версію для ЄС/США)
