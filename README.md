# ЩЁЛК — дизайнерские накладки на выключатели

Статический лендинг с конфигуратором, вдохновлённый форматом printesso.ru
(«дофаминовый декор для дома»): накладки на выключатели света с выбором
количества клавиш, узора и цвета.

Сайт полностью статический (HTML/CSS/JS, без сборки и бэкенда) — открывается
как обычный файл или разворачивается на GitHub Pages / Netlify / любом
статик-хостинге за пару минут.

## Структура

- `index.html` — разметка всех секций страницы
- `styles.css` — стили и превью выключателей на чистом CSS (без картинок)
- `app.js` — данные (цвета/узоры/цены), логика конфигуратора, FAQ, модалка заказа

## Что обязательно заменить перед публикацией

Все значения — заглушки для демонстрации, реальный магазин работать с ними
не может.

1. **Название бренда** — сейчас «ЩЁЛК». Ищите/заменяйте в `index.html`
   (логотип, `<title>`, футер).
2. **Контакты** — в `index.html` (секция `#contacts` и футер) и в `app.js`
   (`TELEGRAM_USERNAME`):
   - Telegram-юзернейм `your_shop_username`
   - Email `hello@example.com`
   - Телефон `+7 (000) 000-00-00`
3. **Цены** — в `app.js`:
   - `KEY_BASE_PRICE` — базовая цена за количество клавиш
   - `surcharge` у каждого узора в `PATTERNS`
   - `surcharge` у покрытия в `FINISHES`
4. **Фото товаров** — превью выключателей сейчас рисуются CSS-паттернами
   (без фотографий), чтобы сайт не зависел от внешних изображений. Когда
   появятся реальные фото готовых накладок, стоит заменить блоки
   `.switch-frame` в карточках каталога на `<img>` с настоящими фотографиями.
5. **Отправка заявки** — сейчас кнопка «Оформить заказ» открывает окно со
   сводкой заказа, которую можно скопировать или отправить через
   `t.me/share/url` (пользователь сам выбирает, кому переслать). Для полноценной
   автоматической отправки в ваш чат подключите Telegram-бота с
   `sendMessage` через свой бэкенд, либо форму на Formspree/Getform и т.п.

## Локальный просмотр

Просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

и откройте `http://localhost:8080`.
